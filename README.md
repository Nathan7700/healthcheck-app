## 🎯 O Problema
Muitos idosos e cuidadores enfrentam dificuldades para organizar horários de medicações, o que pode levar a erros graves, como doses duplicadas ou esquecimentos. 

## 💡 A Solução
O **HealthCheck** é uma aplicação CLI (Linha de Comando) simples e eficaz que permite cadastrar medicamentos e horários, validando a entrada de dados para evitar erros de digitação e garantir que o registro seja confiável.

## 🚀 Tecnologias Utilizadas
- **Linguagem:** Python 3.10+
- **Testes:** Pytest
- **Qualidade/Lint:** Flake8
- **CI/CD:** GitHub Actions
